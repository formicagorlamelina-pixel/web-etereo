# Etéreo Tejidos

Sitio web de venta de amigurumis tejidos a crochet, desarrollado como proyecto final del curso de Desarrollo Web de CoderHouse.

## Descripción

Etéreo Tejidos es un emprendimiento de creaciones únicas hechas a mano. El sitio permite explorar el catálogo de productos, conocer el emprendimiento y realizar consultas de compra.

## Páginas

- **Inicio** (`index.html`) — Hero, productos destacados, video, about, envíos y medios de pago, feed de Instagram
- **Productos** (`pages/productos.html`) — Catálogo completo organizado por categorías: Cantantes, Personajes de ficción, Ramos Eternos, Mascotas y Personalizados
- **Nosotros** (`pages/about.html`) — Historia y presentación del emprendimiento
- **Contacto** (`pages/contacto.html`) — Formulario de contacto y redes sociales
- **FAQ** (`pages/faq.html`) — Preguntas frecuentes sobre pedidos, envíos y medios de pago

## Tecnologías utilizadas

- HTML5 semántico
- SCSS (variables, mixins, @extend, nesting, partials organizados con @use)
- Bootstrap
- Animaciones nativas y AOS/Animate.css
- Diseño responsive mobile-first (mobile, tablet, desktop)

## Estructura del proyecto

├── assets/ # imágenes y recursos
├── scss/ # partials y main.scss
├── styles/ # CSS compilado
├── pages/ # páginas secundarias
└── index.html
